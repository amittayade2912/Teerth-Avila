# Teerth Avila — Original Community Portal Demo

An independently designed static reference website using publicly available project information.

## GitHub Pages
Upload `index.html` to the repository root and enable Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Important
This is not represented as the official society website. Verify any society-specific information (committee, notices, resident data, phone numbers, maintenance amounts, etc.) with authorized society representatives before publishing.
